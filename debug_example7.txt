Análise do código do exemplo #7:

START:
    A=0, C=A, PASSA, ENC    # A = 0
    A=0, C=B, PASSA, ENC    # B = 0

WRITE_LOOP (Iteração 1):
    A=B, B=+1, C=B, ADD, ENC  # B = 0 + 1 = 1
    A=B, PASSA, MAR           # MAR = 1
    A=B, PASSA, MBR, WR       # MBR = 1, escreve 1 no endereço 1 ✓

    A=A, B=+1, C=A, ADD, ENC  # A = 0 + 1 = 1

    A=A, B=-1, C=AC, ADD, ENC # AC = 1 + (-1) = 0
    B=AC, IFZ, GOTO READ_SETUP # AC = 0, então pula para READ_SETUP!

Conclusão: O código só escreve UMA VEZ no endereço 1!

Para escrever múltiplas vezes, o registrador A precisa começar com valor > 0,
ou a condição de parada precisa ser diferente.

Exemplo corrigido para escrever em 5 endereços:

START:
    A=0, PASSA, ENC, C=B    # B = 0 (contador de endereços)
    A=+1, B=+1, B=+1, B=+1, B=+1, ADD, C=A, ENC  # A = 5 (contador de iterações)

WRITE_LOOP:
    A=B, B=+1, C=B, ADD, ENC  # B = B + 1
    A=B, PASSA, MAR           # MAR = B
    A=B, PASSA, MBR, WR       # MBR = B, escreve

    A=A, B=-1, C=A, ADD, ENC  # A = A - 1 (decrementa contador)

    B=A, IFZ, GOTO DONE       # Se A = 0, terminou
    GOTO WRITE_LOOP

DONE:
    GOTO DONE
